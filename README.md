# 가족 항공권 특가 알림 봇

1시간마다 인천·청주 출발 **직항 왕복** 항공권 가격을 모으다가,
노선별 **최근 180일 가격 기록의 하위 30% 미만**인 날짜가 나오면 텔레그램으로 알려줘요.

- 3박4일 ~ 6박7일만 확인
- 한 번 알려준 노선·날짜는 다시 알리지 않음
- 알릴 게 없으면 아무것도 보내지 않음

## 준비물 (3개)

1. **Travelpayouts 토큰** (무료)
   - travelpayouts.com 가입 → 프로필(app.travelpayouts.com) → API token 복사
2. **텔레그램 봇 토큰** — 기존 봇 토큰을 써도 되고, @BotFather에서 새로 만들어도 돼요
3. **채팅 ID** — 날씨 봇에서 받은 숫자 (그룹이면 `-`로 시작, 여러 개는 쉼표)

## 설치

1. GitHub에서 **새 저장소**를 **Public**으로 만들고, 이 폴더의 파일을 전부 올리기
   (`.github/workflows/flight-deals.yml` 폴더 구조 그대로)
2. 저장소 **Settings → Secrets and variables → Actions → New repository secret** 으로 3개 등록
   - `TP_TOKEN` = Travelpayouts 토큰
   - `BOT_TOKEN` = 텔레그램 봇 토큰
   - `CHAT_ID` = 채팅 ID
3. **Actions** 탭 → `flight-deals` → **Run workflow** 로 한 번 실행해서 초록불 확인

## 처음 일주일은 조용해요

무료 API는 과거 6개월 가격을 주지 않아서, 봇이 매시간 직접 기록을 쌓아요.
노선별로 **기록 40건 이상 + 7일 이상** 쌓인 뒤부터 알림을 보내고,
시간이 지날수록 최대 180일치를 기준으로 판단해요.

## 설정 바꾸기 (`config.json`)

| 항목 | 의미 | 기본값 |
|---|---|---|
| `destinations` | 도착지 (IATA 코드: 이름) | 다낭·나트랑·푸꾸옥·세부·보라카이·코타키나발루·괌·사이판·오키나와·후쿠오카·오사카·타이베이·방콕·싱가포르·보홀 |
| `min_nights` / `max_nights` | 여행 박수 | 3 / 6 |
| `months_ahead` | 몇 달 뒤 출발까지 볼지 | 6 |
| `percentile` | 하위 몇 % 미만이면 알림 | 30 |
| `history_days` | 기준 기간 | 180 |
| `min_samples` / `min_history_days` | 알림 시작 조건 | 40건 / 7일 |
| `max_alerts_per_route` | 노선당 한 번에 보여줄 날짜 수 | 3 |

## 알아둘 점

- 가격은 **성인 1인** 기준이에요 (무료 API가 인원별 가격을 주지 않음).
  메시지의 "5명 약 ○○원"은 1인 × 5 어림값이고, 소아 할인은 항공사마다 달라요.
  메시지의 **네이버 항공권** 링크를 누르면 성인 2·소아 3으로 바로 검색돼요.
- 가격은 최근 48시간 안에 누군가 검색한 결과(캐시)라 실제 결제가와 조금 다를 수 있어요.
- 청주 출발 직항은 노선이 적어서 데이터가 없는 목적지는 자동으로 건너뛰어요.
- **Public 저장소 추천**: Public은 Actions가 무제한 무료예요. 1시간마다 2~3분씩 돌면 한 달 약 2,000분이라 Private 무료 한도(월 2,000분)를 넘을 수 있어요.
  토큰은 Secrets에 들어가서 Public이어도 남에게 보이지 않아요 (공개되는 건 코드와 가격 기록뿐).
